1. 报告概览：报告主视觉、年度问题、GOSD → OSDG → OSDI、六章结构。
2. 报告全文：摘要、引言、六章 / 30 节、附录。

6. 发布中心：资料清单、下载与引用、动态解读、版本记录。

全站共用顶栏与页脚。栏目目录、章内定位、面包屑、来源返回、搜索、语言切换、主题切换与移动端菜单共同组成导航。图表条件、指标筛选、演示页码通过 URL 保留。

## 构建

```bash
python3 web/build_portal.py
node --check web/portal.js
node --check web/explore.js
```

无外部运行依赖，托管目录为 `dist/`。`web/build_portal.py` 是本版唯一站点生成入口；它复用 `web/build_reader.py` 的正文与章节编排。不要单独运行旧阅读页生成器覆盖新版导航。

- `content/manifest.json`：六章 / 30 节结构、来源、状态、品牌职责。
- `web/build_portal.py`：共享页面模板、首页与栏目内容。
- `web/base.css`、`web/reader.css`、`web/portal.css`：原有主题与本版响应式样式。
- `web/portal.js`：导航、上下文返回、搜索、指标过滤与演示。
- `web/explore.js`：读取既有 `dist/content.js` 中的图表试读数据。
- `dist/assets/`：原指标与趋势 CSV、框架、结构清单及搜索索引。
