# C-Map 地球：贡献点、样本关系与来源估算

## 三种证据层级

1. **协作机制示意**：96 位虚构开发者、18 个虚构共享项目、384 条关系。双向光点演示开发者与项目相互作用；亮线和光环提示持续投入，淡线提示中断后的衰减。所有位置、权重和持续性均为演示设定，未运行 OpenRank 算法，不构成评分或真实协作记录。
2. **贡献分布与样本实线**：报告 2026 国家点仅采用中国 4,429,200.83、美国 4,239,710.05、印度 894,672.67 三个独立国家值；其他国家不补值。欧洲及全球南方是组别，不拆分到国家。也可切换到 GitHub 2025 自然年，读取完整 236 地区贡献值。实线单独采用 2026 中美项目来源表的 20 条记录：开发者所在地域 → 项目归属地域。
3. **可选来源估算**：金色虚线，是对未列出来源的条件估算。不是未来增长预测，也不是实测跨国网络。默认关闭。

贡献点统计的是地区开发者贡献总量；关系线统计的是特定项目样本的来源。总体不同，不要求节点值等于边的合计。切换点位口径不会改变项目样本流量；图中始终标注各层时期。

## 原表事实

来源：报告仓库 `data/processed/chapter2/table-2-5-1_china_us_project_contribution_top10.csv`，保留原始值与份额。

- 中国项目：前十来源合计 **29,666.10 OpenRank**，原表份额合计 **93.24%**。中国来源占 **79.22%**。
- 美国项目：前十来源合计 **244,808.40 OpenRank**，原表份额合计 **77.94%**。美国来源占 **38.28%**，中国来源占 **7.78%**。
- 同地域贡献以回环表达；该回环是图形符号，不是实际地理路径。
- 项目样本清单、精确窗口、完整分母与未知归属处理仍由数据方补充。以上不等同全体中国或美国项目的总体结构。

## 未列来源的估算假设

对每一个项目归属地分别计算：

- 近似样本总量 = 前十来源贡献合计 ÷（前十来源份额合计 / 100）。
- 待分配贡献 = 近似样本总量 − 前十来源贡献合计。
- 未列来源的估算贡献 = 待分配贡献 × 该来源 2025 GitHub 开发者贡献 / 全部未列来源 2025 GitHub 开发者贡献之和。

这一方法假设未列来源与上一自然年的可观测开发者贡献规模成比例，并将全部残差分配给已识别地域。未知归属、跨年变化和平台覆盖差异都可能破坏这一假设；原表份额还存在舍入误差。因此，这一层只用于展示一种可解释的可能结构，不能作为事实结论、排名依据或政策效果预测。

地球对中国、美国项目分别显示最强 **12 条估算关系，并纳入全球南方六国的估算关系**，避免连线遮挡。全部估算记录保留在 `flows.csv` / `flows.json`；`kind` 区分 `observed` 与 `estimated`，`display` 标识是否画入地球。不推算其他项目归属地。

## 视觉与交互

- 圆点大小：所选口径的地区贡献总量；小灰点仅为来源锚点，没有补算国家总量。
- 实线：2026 原表来源关系。蓝色流向中国项目，青色流向美国项目。
- 金色虚线：未列来源的估算；线越粗，相应样本／估算贡献越多。
- 箭头和单向光点：开发者来源 → 项目归属。不是人员迁移，也不是价值被单向“拿走”。
- 光点速度仅用于方向演示，不代表贡献速度。
- 可选择项目归属、关闭连线、暂停流动，或旋转／缩放地球。减少动态效果偏好会默认暂停。

## 输出、汇入与地域观察

- **全景**：保留点的贡献总量，显示来源到项目的方向和强度。中美项目的外环大小对应原表已列境外贡献，不含估算。初始视角抬高至北半球，便于同时观察中美与欧洲连接。
- **看输出**：仅保留所选地区流向境外中美项目的关系，去掉本土回环。
- **看汇入**：仅保留外部来源流入所选地区项目的关系。中美之外的项目目的地尚未覆盖，显示“未覆盖”，不补为零。
- **南方·估算**：关注印度以及巴西、印尼、越南、菲律宾、埃及、南非；主动开启并醒目标注估算层。当前表列前十只覆盖印度，其余来源的估算沿用同一权重，不人为放大。
- 地区读数卡分开显示对外贡献、跨境汇入和本土建设；估算另列。它们仅描述这两组项目样本，不构成全球净输出或净输入统计。全景中的本土份额使用原表分母，不对前十样本重新归一化。
