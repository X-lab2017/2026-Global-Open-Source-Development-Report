# 第一章 从开放协作到公共价值

开源怎样让更多人参与技术创造，怎样把分散的贡献连接成可以持续发展的技术生态，又怎样产生可验证的公共价值？引言提出共同愿景，本章从具体案例出发，为这些问题建立共同的研究语言。

开放发布使知识和技术有机会被更多人使用，但成果能否延续，还取决于发布之后的参与、维护与再创造。代码需要审查和修复，模型与数据需要清晰的使用条件，新的参与者也需要学习、反馈和承担责任的机会。理解开源发展，既要看见成果的规模，也要看见支撑这些成果的人、组织和协作关系。

人工智能进一步拓展了这一观察范围。代码之外，模型、数据、开发工具和智能体成为相互联系的开放资产；协作既发生在一个项目内部，也沿着采用、修改和后续发布向外延伸。成果数量、网络影响和开放程度分别回答不同问题，任何一个数值都不足以独立说明整个生态的发展质量。

本章依次回答三个问题。1.1 通过 Linux、开放模型与数字公共品，讨论共同创新如何连接公共价值；1.2 以开源发展目标（OSDGs）的四大支柱、十个维度说明希望推动的发展方向；1.3 以开源发展目标指标体系（OSDI）的二十九项指标说明如何组织证据、比较差异与辨认局限。

宣言的七项原则表达共同价值，OSDGs 组织发展目标，OSDI 定义具体观察。三者相互衔接，不作逐项对应，也不合成为一个总分。借鉴联合国可持续发展目标的思路，是为了使问题与证据相联系，不意味着联合国对本报告框架、指标或排名的认证。

全书由此形成“建立基础、展开观察、连接行动”的阅读路径。第二章观察全球开源生态的规模、分布与联系，第三章辨认形成影响的地区、组织和项目，第四章呈现技术分类与演进，第五章追踪模型的供给、复用与开放。四个研究视角相互补充，第六章再将证据汇聚为共同任务与主体建议，落到持续共同创造及其公共价值。

读者可以顺序阅读，也可以按问题进入相应章节。无论从哪幅图开始，都需要先确认观察对象、统计时间和指标含义，再判断它能够支持什么结论。第一章提供的正是这一共同起点。
