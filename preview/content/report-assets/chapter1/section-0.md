# 第一章 从开放协作到公共价值
研究框架与观察方法

开源怎样让更多人参与技术创造，怎样把分散的贡献连接成可持续发展的技术生态，又怎样使这些成果产生可以验证的公共价值？这是《2026 全球开源发展报告》的共同问题。

本报告由中国科协联合国咨商开源创新专委会牵头，关注全球开源生态的发展及其与可持续发展议程的联系。我们借鉴联合国可持续发展目标（SDGs）将共同目标与持续观测结合的思路，提出开源发展目标（OSDGs），并通过开源发展目标指标体系（OSDI）组织证据。三者之间的关联服务于本报告的研究，不意味着联合国对报告框架、指标或排名的认证。

人工智能的发展正在拓展开放协作的对象。代码之外，模型权重、数据集、训练与评估工具也成为技术供给的重要部分。协作既发生在同一个项目内部，也发生在成果被采用、修改和继续发布的过程中。理解开源发展，需要同时看见参与者、开放资产以及连接它们的关系，并进一步追问：谁能够持续参与，哪些成果值得长期维护，开放条件是否清晰，使用者能否在这些成果之上继续创造。

第二至第五章分别从生态格局、贡献主体、技术结构和模型生态展开观察。各章承担不同的解释任务，共同构成从宏观分布到具体协作关系的证据体系。第六章据此讨论行动，将技术生态的观察连接到持续共同创造及其公共价值。

本章依次回答三个问题。1.1 解释开源如何连接共同创新与公共价值；1.2 说明四大支柱、十个维度的目标框架；1.3 介绍二十九项指标及其数据与比较方法。阅读后续图表时，读者可以回到这一框架，确认每一幅图回答的问题，以及它能够支持的判断。
