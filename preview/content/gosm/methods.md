# 第五章：模型生态观察方法与来源

版本：gosm-review-v1。整理日期：2026-10-17。正文、交互图与数据导出共同用于整章评审。

## 1. 阅读框架与前文衔接

沿同一模型版本观察三个问题：谁发布了什么、哪些对象在其基础上继续创造、使用和改进需要哪些材料与权利。模型版本、模型系列、发布账户、机构与国家分别维护，不互相替代。框架是证据组织方式，不表达因果关系，也不合成国家或模型的生态总分。

供给对应第一章 X2 中 OpenModelRelease / ModelSupplierDiv，并联读第二章 A-Map、第三章 E-Ranking / M-Ranking。网络对应 X3 中 ModelRank，与第二章 D-Map、第三章 M-Ranking 衔接。开放条件对应 X4 的 AIAssetTransparency / LicenseOpenness / ComplianceLicenseCov，并与第二章 G-Map 对照。模型仓库的公开可见性不等于已经核验全部开源资格。

## 3. 模型复用网络补充快照

参考项目：[OG-And-HG-2026](https://yaoyao-pig.github.io/OG-And-HG-2026/#huggingface)。采用线上数据声明时间 `2026-10-16T13:35:14Z`，数据文件 SHA-256：`f80759a0fad18de131259467ee3fd1e2164129aa592309e949a991e3a993a396`。

上游：[cfahlgren1/hub-stats](https://huggingface.co/datasets/cfahlgren1/hub-stats)，固定 revision `8d339bcff8f994637cd55e9efbd9dcd9c3b0ae20`。已核对官方Dataset API与固定revision数据卡，许可声明Apache-2.0。参考仓库未见LICENSE，本章自行实现界面，不复用其前端代码。

从原图只取 `base-model` 且 `inferred=0` 的边，统一方向为**基座 → 派生**。结果为5,777个模型、5,111条关系。任务相似、同作者、人工组织关系全部排除。抽取脚本、全量节点/边CSV和元数据同时提供。

- 上游先按数据集顺序取12,000个模型，属于非随机样本；不是Hugging Face全量。
- 上游只保留双端可见的关系，且每对节点按优先级保留一种边；不能据此估算平台全部派生规模。
- 首屏按样本内直接下游数排序，在12个发布账户中各取一个主要基座，加入这些基座的全部直接派生，再保留子集内所有关系：677模型、681边。可切换全部样本，或搜索任一模型进入1/2层谱系。
- 节点大小按样本内直接下游数；全图坐标继承来源位置，概览采用确定性簇群布局。位置、距离和三维纵深不表达指标数值，不称为ModelRank。
- 原图不含国家，不根据模型名、账号或语言推断国家。网络快照与9月13日国家表、8月ModelRank分别展示，不直接跨集合合并。

## 4. 开放分类与补充档案

原870模型：高完整为L3—L5，低完整为L1—L2；高开放为O2—O4，低开放为O1。四类数量为低完整高开放483、低完整低开放212、高完整高开放117、高完整低开放58。

补充快照来自OpenGauge公开API，2026-10-17读取，884模型；四类分别497、212、117、58。两集合缺少身份级对应，不解释为同一群体的改善。补充浏览器保留源站等级、国家、主体和证据入口；本报告未逐项重新评估884模型。

可核对L1—L5名称与19项材料、3项许可字段，但未取得可冻结的完整算法和O1—O4判断表，因此不自行补写等级的权利资格、不重算原870。当前884实际仅有O1、O2、O3，O4为0。

源数据存在三项限制：

1. 地区聚合字段存在美国被归为Other的字符串不一致；补充浏览器只显示原country字段，不使用该错误聚合字段。
2. 许可字段的complete/partial/missing是源站资质判定，不等于文件公开程度；不能将complete转换为“许可已公开”。
3. 22条记录最终开放等级与许可证据raw_value不同，保留原记录并标“许可判级依据待复核”。

四个独立官方案例固定模型版本：Qwen2.5-7B、OLMo-2-1124-7B、Llama-3.1-8B、Gemma-2-9b。2026-10-17核对权重、推理实现、完整预训练代码、数据说明、许可和维护入口。每项列出一手链接与具体判断；未取得充分证据标“待核实”，不认定不存在。案例是目的性选择，不并入870或884的统计，不合成分数，不授予认证。

## 5. 公共价值与行动建议

原评估L/O分级、[OSI OSAID 1.0](https://opensource.org/ai/open-source-ai-definition)及[DPG Standard](https://www.digitalpublicgoods.net/standard)分别适用。DPGA认可依官方程序与Registry记录，本报告不设置金银牌或自行认证阈值。三个小节的九条建议分别连接其图表证据；支持维护、版本化交付与关系记录属于本报告建议，不写成已经测得的因果效果。

## 6. 交互与导出

所有图保留本地控制、口径与来源、当前视角CSV、SVG导出及全屏。网络三维使用现有本地Three.js依赖，可在2D与3D间切换；WebGL不可用时保留SVG网络。二维支持拖动平移和按钮缩放；三维支持旋转与缩放。减少动态效果偏好下不播放持续动画。

框架属于概念关系；其数据导出为视角与指标映射。网络导出当前视角实际边集，完整节点/边见源文件。三维模式下SVG导出同一关系集合的二维布局，按钮相应标为“2D SVG”。开放档案SVG为证据摘要，完整说明与一手链接保留在HTML和CSV中。各图不同日期与样本范围随导出保留，不能将导出数字跨口径加总。
