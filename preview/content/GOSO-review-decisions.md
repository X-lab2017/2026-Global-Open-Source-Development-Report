## 实现与评审边界

七节正文、七组交互图（19 个视图）、15 份原始数据、静态图、数据表、CSV 和当前图 SVG 下载。浏览条件写入 URL；页面末尾提供四组评审备注，备注仅在当前浏览器保存，可导出 Markdown。

本次仅更新既有 owner-only Sites Preview。未向报告 GitHub 推送或更改 GitHub Pages，未覆盖报告原稿与数据。批准后再迁移本章稿件、图表与生成器至正式仓库。

验证包含全站导航、来源/文件字节一致性、数据与图件结构、JS 语法、重要增长值和未知覆盖率。环境未提供 control-browser 能力，未进行浏览器视觉与交互实测。

## 复用方式

`web/goso_content.py` 保存样章正文、图表配置及导出规则；`web/goso.js` 与 `web/goso.css` 提供共享交互和版式。其他核心章节复用“问题—判断—证据—解释—边界—行动线索”的结构，保留自身研究对象与图形选择。
