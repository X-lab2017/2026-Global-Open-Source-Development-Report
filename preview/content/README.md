# 报告内容架构

本目录通过 [manifest.json](manifest.json) 维护目录、稳定编号、双语标题、页面类型与内容状态。网页由仓库源稿与专题数据构建。

## 阅读结构

执行摘要 → 引言 → 六章正文（30 个小节）→ 附录 A、B。附录 A 为“指标、数据与研究方法”，附录 B 为“模型开放条件与数字公共品研究参照”。宣言全文与简明来源说明收录于引言，原宣言附录的网址保留为跳转入口。

第四章 4.2—4.6 目前提供全景图与研究框架，其余内容按实际证据状态呈现。框架、文件入库、指标测算和结论核验分别记录。

## 同源正文与发布

- 附录 A 的中文源稿位于 `appendices/附录A-指标体系与数据来源.md`，英文源稿为 `appendices/appendix-a.en.md`。网页与中文 PDF 使用相同正文。
- `import_report.py` 更新正文、文件清单和来源快照；`report.json`、`frontmatter.json` 是生成副本。
- `build_publication_pdfs.py` 从当前源稿生成附录 A PDF，并同步前置合订版的目录与范围说明。原第一章 PDF 整页保留。
- `build_portal.py` 统一生成目录、前后篇章、搜索与下载入口。方法附录保留已发布的旧锚点。
- 发布检查核对链接、完整正文、数据文件校验值、PDF 书签、文字边界与页面尺寸。自动检查与人工视觉核验分别记录。

## 清单约定

`source_path` 指向仓库源稿；`status` 记录篇章状态，`data_status` 与 `research_status` 保留证据状态。更新编号时同步关联引用，既有路由与章节锚点保持可用。

出版通则见 [网页与 PDF 出版基线](../print/BASELINE.md)，专题方法保留在相应内容目录。历史审定记录保留，不随内容更新覆盖。
