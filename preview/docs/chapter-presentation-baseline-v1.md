## 2. 共同的阅读逻辑

**先看全貌 → 按需探索 → 就近查证 → 回到正文。**

每一小节围绕一个明确的问题或判断组织内容。正文解释研究意义，图表给出关键证据，表格支持精确对照，来源与口径紧邻相关图表。需要补充的事实继续明确标注。

- 一幅主图聚焦一个主要问题。复杂内容可分为图组、标签页或相互关联的两幅图。
- 默认状态应展示结构或主要结论，读者不必逐个点击才能理解基本内容。
- 选择一个对象后，在固定区域替换详情；全貌、选中对象与解释保持可见。
- 正文连续阅读，单幅图表尽量单屏。细节过多时优先减少同屏项目或分页，保持文字可读。
- 不为增加动态感加入流动连线、循环动效或自动播放。

## 3. 视觉与排版

| 项目 | 基线规则 |
|---|---|
| 品牌 | GOSD 为报告主标识；OSDGs 为目标框架，OSDI 为指标体系；沿用现有品牌资产与主题色 |
| 页面导航 | 统一六项顶栏、章节侧栏、稳定节锚点、面包屑与前后章节链接 |
| 阅读版式 | 正文沿用报告阅读样式；图表使用独立的无衬线字体、行距、字重和间距 |
| 图表层级 | 图号／类别、标题、简短操作说明、主图与详情、来源／口径；标题与来源不能挤占主图 |
| 主图画幅 | 第一章交互图以 1280 × 800 为设计坐标，按可用空间等比缩放；后续复杂图可以调整画幅比例，仍须满足单屏展示 |
| 表格画幅 | 短表按信息量采用紧凑高度，当前参照为 580／620／680；长表参照为 720，设计宽度均为 1280 |
| 字号 | 第一章图题约 28–29 px，主要图中文字约 17–22 px，对照表正文约 20 px；这些是设计画幅字号，缩放后仍须实际检查可读性 |
| 颜色 | 颜色表达类别、选择或已定义的数据含义；支柱颜色不代表四个研究章节的一一映射 |
| 主题 | 明暗主题下的正文、选中态、边界、图例与导出保持清晰，沿用已合并的品牌图表规范 |

第一章专有结构继续保留：SDGs → OSDGs → OSDI 位于第一章框内；六章卡片协调；第六章文字完整可见。后续章节复用呈现规则，不重复放置整套第一章概念图。

## 4. 交互、表格与查证

1. 全文浏览和全屏模式采用同一内容与同一套排版规则。全屏按钮、退出按钮及 Esc 行为一致，退出后回到原来的阅读位置并保留选择。
2. 图表切换不改变画幅高度，不产生图表内部纵向滚动条。悬停提示同时提供点击、触控或键盘入口。
3. 短表保留全部行列，适合一眼对照；长表在固定画幅中分页，始终显示当前范围和总条数。当前参考每页 8 行；长文本表可减少每页行数。
4. 完整数据表可在图表外独立折叠，展开后的表格也遵循单屏分页。逐月数据和完整指标词典保留原始记录与来源入口。
5. 来源、统计期、观察对象、单位、缺失值及关键解释边界与图表相邻。外部开篇故事与 OSDI 测算分开标注。
6. 不通过裁切文字、隐藏溢出、删减记录或混合统计口径来满足单屏要求。必要时调整信息分区、拆分视图或分页。
7. 图内链接可以返回相关正文或进入详细证据；同页跳转须先退出演示，避免被全屏层遮挡。
8. 打印展开完整记录；下载文件保持来源数据；无脚本时保留可读默认图形、语义表格和静态下载入口。

## 5. 各章节的适配方式

| 章节 | 优先图形 | 建议交互 | 共同要求 |
|---|---|---|---|
| 第二章 GOSO | 全球／中国地图、结构比较、趋势与流向 | 地区选择、指标／年份切换、地域下钻 | 地图与解释并排；完整说明未知地域及统计口径；保持中国地域呈现一致 |
| 第三章 GOSR | 排行榜、贡献与影响对照、位次轨迹 | 排名对象／指标切换、分页、对象详情 | 排名口径、时间窗、样本与缺失说明可见；长榜单不撑高图框 |
| 第四章 GOSL | 技术全景、分类矩阵、项目关系 | 层级／类别切换、项目详情 | 一眼看清全景分类；大图容量不足时按清楚的分类边界拆为两幅 |
| 第五章 GOSM | 供给结构、采用／派生关系、开放条件 | 月份／模型系列切换、详情与证据 | 区分代码年度、模型月度及补充快照，不用同一横轴暗示完全可比 |
| 第六章 行动建议 | 行动矩阵、责任分工与推进路径 | 按行动主体或优先事项切换 | 建议与前文证据对应，数据缺口和待定事项明确保留 |

每次接入后续章节，先完成一个代表性小节，再按同一规范处理该章其他图表。章节图形根据问题选择，避免为统一外观改变研究表达。

## 7. 验收要点

- [ ] 普通全文浏览可读，标题、图例、正文、卡片与脚注均在所属区域内。
- [ ] 进入全屏、切换到最长文本／最多项目状态、退出全屏，内容和排版保持完整。
- [ ] 宽屏、普通笔记本、低高度窗口及窄屏均检查过；单屏与字号可读性共同验收。
- [ ] 首项、末项、所有分页与空值状态可访问，分页不会丢失或重复数据。
- [ ] 键盘焦点、Esc、同页返回、主题切换、打印和原始下载可使用。
- [ ] 中英文界面及较长标签有足够空间，不把界面翻译视为正文翻译已完成。
- [ ] 图表记录与原始数据一致；来源、时期、单位与解释边界可查。
- [ ] 共享样式调整后复查第一章，其他章节正文与事实数据未被意外改写。
