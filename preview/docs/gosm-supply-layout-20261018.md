# 5.1 三图布局优化 · 2026-10-18

基于7b6921d的一屏版本，仅优化5.1三图的布局与交互。

- 中美指标卡增加上下边距；条形图与样本注释之间增加分隔和独立留白。分母在图面使用万／亿，悬停或数据表保留精确值。
- 三图榜单每页6条，38／40／48单位行距，名称按可用宽度截断，完整名称在悬停和精确数据表中保留。中美两国的行条和选择色分别保持蓝／金。
- 图表分为总览、排名、所选对象详情。地图详情增加组织榜入口；组织视角支持直接返回地区排名，搜索提供空态。未选国家时组织切换禁用并给出提示。
- 趋势区独立分配标题、切换和绘图空间。保留全球月度与年度序列及其数据口径。
- 筛选控件按用途分行，增加按钮尺寸和间距。键盘操作保留焦点；活动控件提供按下状态。
- 桌面全屏继续适配可用空间。窄屏与较矮屏幕允许图内滚动，避免文字无限缩小。

验证：DOM状态检查涵盖3图、明暗主题、6条分页、筛选空态、国家／组织／省级下钻、趋势选择、集中度、导出和全屏；专门检查样本注释距条形下缘至少20单位、距卡片底部至少16单位。原生SVG渲染检查三图与选中状态。源数据与5.2、5.3正文保持不变。

限制：当前环境无Sites要求的control-browser能力，未执行真实浏览器布局或触摸实测。
