# 5.1 一屏显示与阅读间距平衡

三幅图统一采用 1280 × 560 的逻辑画布，桌面图框高度随窗口变化，预留顶部导航与页边距，取消 700px 高度下限和矮窗口内强制滚动。

- 全球：将所选对象详情移至地图下方、榜单左侧，减少纵向堆叠；下方保留两条全球趋势、时间窗口及当期值。
- 中美：保留指标卡片分母与条形图之间 20 个逻辑单位的净距，六行榜单与两行发布者详情；完整精确值继续保留在数据表和导出。
- 中国：减少地图、榜单与底部详情之间的空白；保留省级与组织切换、搜索、分页和选中信息。
- 界面：标题与图号并排，工具与筛选采用 30px 最小高度；手机保留可读画布与局部横向浏览。

验证：构建与章节数据检查、10 幅图的 DOM 交互回归、CSV/SVG 导出、明暗图面 SVG 渲染、1920×1080／1440×900／1366×768／1280×720／1280×680 的 CSS 高度预算。浏览器控制技能不可用，未进行真实浏览器排版与触摸验证。
