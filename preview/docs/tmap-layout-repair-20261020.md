## 协作连接图

- 跨地域协作：平铺五域选择，地图与去向排行联动；点击连接或排行聚焦单条关系，也可恢复全部去向。地图节点表示地域组，不表示人口迁移。
- 技术领域：按模拟人数绘制比例流带，保留来源与去向的总量守恒；默认显示全部，可选择单一来源、去向或连接，右侧同步解释选中关系。
- AI 贡献角色：以色深呈现角色构成，点击矩阵后在右侧查看对应领域的四类角色分布。浅色、深色主题共用清晰的文字层级。
- 保留“模拟数据｜待替换”标记，不将模拟关系写成实测结论。原始观察数据与模拟 JSON 指纹均未改变。

共用正文、源章节、网页、下载底稿及 PDF 同步删除成长接续内容并调整编号。旧 `fig-2-4-5` 锚点继续引向协作连接图，避免已有链接失效。PDF 的技术流带同步采用比例宽度，角色矩阵同步增加色深层次。
