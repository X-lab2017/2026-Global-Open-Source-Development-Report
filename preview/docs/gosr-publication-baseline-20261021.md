## 已确认的 20 条规则

1. 政府与国际组织决策者优先，以事实解释意义，兼顾产业与学术读者。
2. 章首保留导读、核心问题、主要观察、主题入口；统计期集中说明一次。
3. 小节沿用导入、问题、指标、发现、图前分析、证据、图后解释、行动与衔接；允许按内容精简。
4. 图文各有职责，不抄录整个榜单，不用交互操作提示替代研究叙事。
5. 正文与第一章同栏宽，图件居中，避免局部左窄栏。
6. 每图完整编号与名称置于图下居中，随全屏保留，删除外部重复题签。
7. 图件可独立阅读，保留对象、单位、图例和必要数据状态。
8. 主体优先、顶底精简、按内容调高；窄屏不缩成不可读小字。
9. 每章一个口径与来源入口，置于首图；不恢复各节末尾统计说明块。
10. 默认统计期为 2025-07-01 至 2026-06-30；例外保持真实范围，避免重复时间徽标。
11. 缺失不补零；模拟醒目标注，不用于真实排名和实测结论。
12. 行动建议明确主体、做法、进展观察，并与第六章衔接。
13. Web 与 PDF 的正文、数据、结论、图义及文字删改同步，媒介编排可不同。
14. PDF 默认 A4 竖版、正文约 11.2 pt；复杂图可少量横向或续图，不固定页数。
15. 整章与合订 PDF 不上传 GitHub；评审文件通过聊天交付。Web 与 PDF 分别记录版本。
16. 地区、组织、项目、仓库、模型等对象清楚定义，不混合层级排名。
17. 同榜统一时间、指标与筛选条件，跨年比较须确认范围和映射可比。
18. 区分数值增长、位次变化、新进入和退出，不用升位代替绝对增长。
19. 图数由研究问题和证据决定，不强制每节三图。
20. 分节同步验收，合章再查目录、页码、书签、图题、清理残留和下载版本。
