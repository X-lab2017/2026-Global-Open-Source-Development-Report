# GOSO 2.1—2.4 系统对齐记录

本轮以第一章 v0.12.5 和已确认的 V-Map / C-Map 为参照，将 I-Map 与 T-Map 接入同一报告构建。内容、交互和样式同时对齐；原稿与根目录研究数据不改写。

## 统一的阅读结构

研究问题 → 目标与指标定位 → 核心发现 → 全球全景 → 五域比较 → 中国观察 → 策略建议 → 待补证据与下一节。

| 小节 | 观察对象 | OSDGs / OSDI | 接续关系 |
| --- | --- | --- | --- |
| 2.1 V-Map | 实际参与与地理分布 | X1 / 1.1 · DevScale | 参与基础进入持续协作 |
| 2.2 C-Map | 开发者的社区贡献 | X2 / 2.1 · OpenRankContrib；DevScale 辅助 | 贡献所在地与项目归属分别观察 |
| 2.3 I-Map | 全域网络中的项目侧影响 | X3 / 3.1 · OpenRankInflu；GlobalCollabShare 为样本诊断 | 项目的长期联系由人建立和维护 |
| 2.4 T-Map | 全域网络中的开发者侧人才 | X3 / 3.1 · HighImpactTalent；交叉呼应 X1 人才议题 | 从人才积累接续 2.5 跨地域协作 |

SDGs 提供价值方向；OSDGs 组织研究议题；OSDI 提供可检验指标。图表是指标的观察入口，尚未完成聚合、去重或覆盖核验的样本不直接视为完整 OSDI 测算。人数、贡献与网络影响分别计量，不计算“贡献转化率”。

T-Map 继续采用三个实测图组作为主线；成长、留存、跨地域连接和 AI 角色两组模拟放在补充探索位置。模拟说明随图保留，既不形成实测结论，也不用于预测政策效果。

## 统一的呈现和操作

- 修复 I-Map 的 CSS 解析错误：`@charset` 被旧 CSSOM 解析器并入首个选择器，导致浅色主题变量未生效，出现黑色地图、不可见按钮文字和丢失的曲线颜色。作用域内固定浅色、深色变量，增加发布检查。
- 八个新增图组复用第一章的演示生命周期：图外右上方“全屏演示”、固定演示栏“退出演示 Esc”、返回原位并保留筛选状态。正文按宽度和视口高度共同缩放，不在图内垂直滚动。
- 图内统一标题层级、青蓝色调、顶部分段切换、右侧年份／口径、来源按钮、右侧详情和底部分页。地区颜色与 V-Map 的身份对应保持一致，C-Map 趋势也按身份映射。
- I-Map / T-Map 使用同一份 `content/vmap/map-geometry.json`，不重复投影、简化或存储另一套几何形态。中国包含台湾省。
- 阅读模式和演示模式共用同一 DOM 与样式；事件委托同时覆盖正文和演示对话框。说明对话框、键盘选择、Esc 返回和移动后点击均有交互检查。

## 构建与数据

唯一入口仍为 `python3 preview/web/build_portal.py`。新增 `web/goso_maps.py` 读取 `content/imap` 和 `content/tmap`，从既有地图生成几何字段，再导出网页运行数据。Sites 与 GitHub Pages 使用同一组源文件。

2.3 保留 2025 自然年快照、2022—2026 报告序列及国际贡献样本各自的边界。2.4 保留全球 175 条记录、中国 370 条定位记录及五域／十城序列。人才源表年度／累计定义、前 5% 总体及并列处理待核验；中国项目数量序列仍留空。模拟在独立 `simulation.json` 中维护。

## 验证与限制

执行全站构建与链接检查、第一章／V-Map／C-Map／GOSO／GOSR／GOSL 既有检查，以及新增的 I/T 颜色变量、指标映射、下载 CSV 和模拟隔离检查。DOM 交互检查覆盖所有视图、年度和地区、完整分页、演示后点击、来源说明、Esc 退出和筛选保留。

当前环境没有受支持的浏览器视觉验收工具。本轮未作真实浏览器截图或移动端触控实测；渲染效果仍需上线后人工评审。已知的颜色变量问题通过具体根因修复与静态检查防止回归。
