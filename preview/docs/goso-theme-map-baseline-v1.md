## 2. 叙事模板：一个问题、三组证据、三个行动方向

| 顺序 | 内容 | 写作要求 |
|---|---|---|
| 主题入口 | 节号＋“XXX地图（X-Map）”＋核心问题 | 主题词清晰，主张能用一句话表达 |
| 核心发现 | 一段主判断＋三条简短发现 | 判断区分已观测事实、解释与待验证假设；避免用榜单罗列代替洞察 |
| 指标定位 | OSDGs 维度／子目标 → OSDI 指标 → 本节用法 | 主指标、辅助指标、派生分析和暂未使用指标分清；SDG 对应以第一章词典为准 |
| 证据一 | 全球全貌 | 说明主题的地理分布与全球意义，兼顾全球南方 |
| 证据二 | 固定比较组与变化 | 绝对规模与相对变化互相补充；组成员、年度及平台范围一致 |
| 证据三 | 区域下钻与可迁移经验 | 中国作为区域实例，说明内部差异及可以进一步验证的机制 |
| 策略建议 | 三项与证据对应的行动 | 采用联合国和全球视角；指出行动主体、行动与可观察的后续进展 |
| 指标反馈与衔接 | 用了什么、还缺什么、下一节回答什么 | 只集中列出会改变结论的缺口；与第六章行动建议形成闭环 |

2.1 已接受的证据主线为“全球 → 五域 → 中国”，建议为“实际参与长期监测 → 全球南方作为共建伙伴 → 区域节点承接长期合作”。这些是 V-Map 的内容基线。C-Map 可沿用三层尺度，其他小节按研究问题选择流向、治理或资产等表达，不机械要求每节都有三张地理地图。

## 3. 地图与交互

1. 全球与中国地理主题图以 OpenShare 的同源 `world.json`、`CN.json` 为形态参照。保留原始边界和附图；按源平台的经纬度布局及 `aspectScale=0.75` 复现，再统一等比缩放。不得为了填满卡片单独拉伸横轴或纵轴，不自行改用另一投影。
2. 实现与来源记录见 `web/build_vmap_geometry.py`、`content/vmap/map-provenance.json`。世界与中国原始坐标点共 40,959 个；不简化轮廓。后续更换底图要另行记录来源、几何差异与审阅结果。
3. 世界地图的中国地域呈现与中国下钻一致；台湾省、香港特别行政区、澳门特别行政区在中国省级视图中呈现，保留源图的南海相关边界及附图。全局排名与省级排名使用相应层级，避免重复计入。
4. 图号统一为“图 2-节号-序号”。主图、榜单、选中详情与简短趋势联动，默认画面就能传达主要发现。原稿截图保留为对照证据，不替代交互图。
5. 延续第一章固定画幅：当前地图画幅为 1280×860，比较图为 1280×800；正文与全屏共享同一画布并等比缩放，不出现图内纵向滚动。不能通过裁字或隐藏数据解决拥挤。
6. 排行长列表用分页或对象搜索，不靠图内滚动查看末项。悬停同时提供点击、触控及键盘入口；选择、下钻、返回、重置、退出全屏保留可预期的状态。
7. 颜色、图例、选中态及明暗主题沿用已合并的品牌规范。地图颜色表示数值，不暗示发展等级或价值高低。不同主题使用相应单位与图例，不因复用组件混用人数、贡献度和影响力。

## 4. 数据口径：固定规则，允许数值更新

每个图形数据集登记：来源 URL／仓库路径、抓取日期、源版本／哈希、统计期、平台、指标定义、地域层级、聚合规则、缺失处理与用途。未知不等于零，表列数据、派生计算、情景和预测必须可辨认。

| 当前 2.1 数据层 | 已接受的处理 | 后续复用的规则 |
|---|---|---|
| OpenShare 自然年基线 | 2025-01-01 至 2025-12-31；GitHub；中国活跃 2,344,657.55，按原图显示 234.46 万 | 默认地图、排名、比较和下钻使用同一版本／窗口 |
| OpenShare 报告年 | 2025-07-01 至 2026-06-30；中国活跃约 250.48 万，与自然年分别保存 | `/gosd` 路径名称不替代元数据；不把两套窗口视为同一年度 |
| 仓库五年序列 | 2022—2026 原始表保留，差异及待对齐状态可见 | 不与当前自然年拼接，不据未对齐序列得出本期增长结论 |
| 国内平台补充 | Gitee＋AtomGit 约 120 万，仅两平台之间已说明去重；与 GitHub 重叠等待核 | 约 354 万仅为净新增假设情景；不认证跨平台独立人数，不分摊到省份和历史年份 |
| 2021—2025 小趋势 | 使用已取得的同源实际数据 | 有实际序列优先用实际序列；缺年留空；如另行采用预测须醒目标注方法和范围 |

五域指美国、欧洲、中国、印度、全球南方代表六国（巴西、印度尼西亚、越南、菲律宾、埃及、南非），是固定比较组而非全球五大洲或穷尽分区。六国组不代表全部全球南方；中国、印度单列不表示其不属于全球南方。欧洲成员未对齐时显示待补，不自行补造汇总数。

全球总量与地域明细合计存在差额时，保留两者并说明待核原因，不自动把差额解释为“未知地域”。人数使用原始精度做计算；与 OpenShare 对照的万位读数保留平台截断显示方式，小非零值不显示为零。

国内人数开关不自动适用于其他指标。C-Map 若要加入国内平台，必须取得贡献度的算法、归一化、覆盖和合并依据，不能将 120 万开发者换算成 OpenRank 值。

## 5. 指标反馈模板

> 本节对应 OSDGs 的 **[维度／子目标]**，以 OSDI 的 **[主指标]** 观察 **[对象与问题]**，用 **[辅助指标]** 作对照；**[份额／增量／平均值等]** 是派生诊断，不自动成为新增指标。与 **[SDG 编号]** 的联系沿用第一章。**[尚未核验的字段映射／年度／分母]** 完成后再纳入正式 OSDI 测算。

增加一个指标前，先判断现有指标是否已能回答问题。活跃增量不替代新进入者增长；平均 OpenRank 不替代人才质量、劳动生产率或社会效益；地理相关性不自动证明产业、教育或政策的因果机制。
