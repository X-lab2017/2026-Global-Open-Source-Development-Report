# 5.1 第二、三幅图对齐主体优先的布局

延续第一幅图通过评审的风格，三幅图统一保留一排主要控件与“数据与导出”菜单，维持 1280×560 逻辑画布和一屏高度适配。

- 中美对照：四项规模指标改为中美并排，卡片高度由 164 压至 120，保留条形图与分母文字至少 20 个逻辑单位的净距；榜单行高由 32 增至 44，集中度曲线高度由 142 增至 224。底部压为“所选账号／本国份额／原页入口”一行，具体模型与数据集数量可悬停读取。
- 中国地图：地图尺度由 0.79 增至 1.02，顶部统计合并为一行说明；分页放在右侧榜单下方，复位与返回操作放在地图，底部详情高 64。省级归属待补继续保留，地图边界与数据口径不变。
- 交互：资产切换平铺，次级观察选项使用紧凑选择框。地区榜与组织榜切换时清空搜索；以组织数观察地区后进入组织榜，自动按资产数量呈现具体发布者。

验证：章节构建和数据口径检查；三幅图筛选、搜索、分页、下钻、菜单、表格、全屏及 CSV/SVG 导出；明暗主题 SVG 图面检查。未进行真实浏览器排版与触摸测试。
