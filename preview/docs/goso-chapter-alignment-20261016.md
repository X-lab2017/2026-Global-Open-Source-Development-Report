# GOSO 第二章整章呈现对齐 · 第一轮

日期：2026-10-16。基于已合并的 2.1—2.7 审阅版本；本轮负责呈现、交互和导航，不替代专家对事实、统计口径和结论的判断。

## 七节阅读顺序

V-Map 活跃 → C-Map 贡献 → I-Map 项目影响力 → T-Map 人才 → A-Map 资产 → D-Map 多样性 → G-Map 治理与社会公益。

统一框架：核心问题、目标与指标定位、核心发现、图表证据、三项行动建议、指标反馈与待补证据、前后节导航。保持不同主题所需的图形和证据层次，不为统一而删去研究内容。

## 图表操作约定

- 26 幅图按“图 2-节-序号”编号。保留既有锚点，同时新增统一编号锚点。
- 来源和全屏演示放在图表上方右侧；图内保留同位置的来源入口。
- 演示使用第一章既有的固定画幅缩放机制；正文与演示移动同一图表节点，保留选择状态。
- 演示顶部可切换上一图、下一图；也可用 PageUp / PageDown，Esc 返回正文。
- 地图、筛选、分页、来源弹层和桑基／弦图联动继续沿用既有行为。
- 浅深主题共用报告色彩与文字层级；国家配色延续前四节。资产类别继续使用类别配色。
- 模拟、预测、来源样本和待补项目的标签继续保留。

## 验证范围

完成七节／26 图／21 项行动建议的结构检查，旧锚点、来源链接与 GitHub 项目路径检查；DOM 回归覆盖 26 个来源入口、26 个演示入口、四种缩放宽度、跨图前后遍历、状态恢复以及桑基／弦图相同关系与数值。运行既有 Pages 构建和各章守卫，核对原始 CSV 与地图几何保持不变。

当前环境没有可用的受支持浏览器控制能力；DOM 和缩放计算检查不等同于真实浏览器逐像素验收。发布后优先人工复核窄屏文字、横屏演示与 WebGL 地球。

可复现的补充交互检查：提供 jsdom 26 后，运行 `node preview/web/check_goso_reading.cjs _site /2026-Global-Open-Source-Development-Report`。
