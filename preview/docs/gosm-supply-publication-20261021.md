# 5.1 供给与贡献：出版级阅读优化

本轮沿用已确认的章节阅读基准，只调整 5.1 的正文、图件呈现和静态 PDF；5.2、5.3 的内容及供给数据不变。

- 共享正文按全球积累、中美发布主体、中国区域节点展开，明确研究问题、指标定位、核心发现与责任主体。行动建议均附可观察的成效。
- Web 保留全球、双国、中国三个交互全景，统一为图 5-1-1—5-1-3，题名居中置于图下；全屏与 SVG 导出保持相同题名。口径与来源集中于一个折叠入口。
- 首图默认展示与核心发现对应的年度回溯，保留月度切换、资产切换、地域和组织下钻、搜索、数据表及导出。筛选不改变统计分母。
- 私有审阅 PDF 为六页；全球全景横版，年度回溯与月度新增分区；中美比较以 A 模型、B 配套数据集分图呈现，分别比较规模、前六账号和下载集中曲线；中国图保留省级归属待补记录与原始地图几何。
- 平台总览、地域样本、年度回溯和月度新增分别保留真实窗口。826 个地域组织、73,088 个模型及 12,502 个配套数据集均来自原固定快照，不外推全球贡献或模型能力。下载和点赞不作为采用人数或贡献质量。
- 图表颜色、文字和数据口径由同一份正文与原记录生成；PDF 页内提供在线来源链接。PDF 与渲染图不进入公开仓库。

验证：站点构建与链接检查、GOSM 全图数据一致性检查、39 项 5.1 交互与出版回归；PDF 六页视觉检查、共享正文逐段校验及来源链接校验。共享渲染器的兼容改动同时检查 5.2、5.3 图件初始化。

主要入口：`gosm_supply_content.py`（共用正文）、`gosm-supply.js` / `.css`（交互与版式）、`gosm_supply_print.py`（私有 PDF）、`check_gosm_supply_publication.cjs`（回归）。
