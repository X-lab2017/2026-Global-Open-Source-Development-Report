# 2.4 T-Map 图文与出版优化

本轮沿用 2.1 / 2.2 基线，状态为提交评审。五幅图、原始 CSV、`observations.json` 与 `simulation.json` 数值全部保留；不抓取另一份数据替换既有样本。

- 共用正文：`web/tmap_publication.py`；同步源章节、网页、下载底稿与 PDF。
- 叙事：全球分布 → 五域变化 → 中国十城 → 成长接续 → 协作连接 → 三项行动。图前提出问题，图后解释证据及适用范围。
- 网页：五图统一使用第一章演示生命周期，1280 × 860 设计画布；正文与全屏复用同一 DOM，宽度不足 700 时重排。图头保留主要视角，来源置于底部；修复年份切换后底部仍显示 2026 结论、散点近邻标签重叠等问题。
- PDF：7 页，全球地图为第 2 页横向页；图 2-4-2 至图 2-4-5 各与相应文字同页。五幅矢量图保留网页的地图、趋势、哑铃、队列矩阵、留存条形、关系流线与角色矩阵结构。题注下置居中，图内文字 8.5—10.5 pt，正文 11.2 pt。
- 模拟：图 2-4-4 / 2-4-5 醒目标记“模拟数据｜待替换”，不改成实测或政策预测。实测图与模拟参数独立存放。

## 数据核对与保留事项

原稿附件的全球 35 万、同比 7.9% 和五年增长 38.1% 尚无独立全球汇总表支撑，正文暂不采用。世界记录合计为 167,645，不能用来填补或重算全球总量。原稿折线图的部分起点与已锁定 CSV 不一致，本次仍以当前网页和 CSV 为准，不默默切换版本。

全球快照为 2026 年 7 月；五域及十城序列沿用报告年度。中国 12,653（地图）与 13,100（五域）保留各自范围，不能混接。原稿京沪 45.2%、前五城 71.6% 所用定位分母未单列，现有定位表混合层级；本版改用可直接复算的“京沪占固定十城净增量 49.3%”。源表 Top 5% 的累计窗口、基准总体与并列处理仍待补方法，不把人才数增长解释为质量、迁入或培养成效。

## 验证范围

已核对五幅矢量图和全部 7 页 PDF。426 项双语页面 DOM 交互断言通过，覆盖视角、年份、图内选择、搜索与分页、模拟参数、来源弹窗、全屏返回、窄屏分支。180 项 CSS 级联断言覆盖明暗主题及正文、全屏、窄屏容器。出版检查锁定数据指纹、跨版正文、图件几何、模拟标记、PDF 字号与页界。

当前环境无受支持的真实浏览器，本次未执行真实浏览器截图或纸面打印；DOM/CSS 与 PDF 检查不能代替这两项。请评审真实浏览器中的字号密度、视角切换与图文节奏。
