# 2.6 D-Map 多样性地图审阅版

本轮更新现有私人审阅 Site 的第二章 2.6；2.1—2.5 与 2.7 的正文保持原样。三幅图共九个视图，采用既有 1280 × 820 单屏画布与全屏演示机制。

## 图组与操作

1. **图 2-6-1 参与广度**：贡献来源地图、五年格局、新兴参与六国观察。地图沿用已确认的 OpenShare 几何，台湾包含在中国图形中。
2. **图 2-6-2 跨境协作**：左桑基图、右有向弦图同屏；共享国家、方向、本地贡献开关、数据集与度量。节点/连线悬停同时高亮，点击锁定，支持键盘选择。默认中美汇入；可以观察输出、双向和其他地区。另设协作地图及中美来源份额对照。
3. **图 2-6-3 持续共建**：组织结构矩阵、贡献角色与持续参与曲线。全部为假设社区设计模拟，六种情景不对应真实国家或项目。

三项主张：参与代表性的长期观测、全球南方的长期伙伴网络、支持不同参与者持续贡献。组织构成不被当作治理权力；协作流向不被当作人员迁移。

## 数据边界

- 2025 自然年地图使用已有 C-Map 同源快照，236 个已列地区、贡献合计 18,523,442.24。份额分母只限已列地区，未知所在地的完整分母待补。
- 2022—2026 份额序列来自报告原表，美德中英印为固定选集。其合计份额 49.47% → 48.62%；其他国家 50.53% → 51.38%。其他国家不能直接等同全球南方。
- 原稿流向表有 60 条关系，14 个来源、10 个项目归属地区。中国目的地合计 52,614.39，美国 402,786.40；是样本贡献，未列关系不等于零。
- 中美 Top 10 来源份额是独立样本。本地份额中国 79.22%、美国 38.28%；海外补集为 20.78%、61.72%。未列明其余来源 6.76%、22.06% 保留为合计，不推断国家或绝对贡献值。两个数据集不混算。
- “贡献规模”保留原始 OpenRank；流向样本的“来源结构”按当前筛选中的每个目标归一为 100%。独立来源份额表则始终保留原表百分比，不因隐藏本地贡献重新归一。
- 弦图外弧合计当前显示的输入与输出，本地关系占两个端点；箭头指向项目归属。两图输入为同一关系矩阵。
- 第三图数据在 `collaboration-scenarios.csv` 独立保存，状态为 simulated；不计入 OSDI 正式测算，不支持因果结论。

## 文件与后续替换

`portal-source/content/dmap/source/` 保存原始 CSV 与本轮附件；保留原 CSV 的历史图号以便追溯。页面统一使用 2-6-1 至 2-6-3。`source-manifest.json` 记录来源与限制。

从来源重建：`python tools/dmap/prepare.py`。

构建：`python tools/build-aligned.py`。

行为验证：`node tools/check-dmap.cjs`，可用 `DMAP_JSDOM` 指定已安装 jsdom 的模块路径。

优先补齐：完整同口径来源与流向、时间窗口及未知地域分母；贡献时点的机构与角色关联；首次贡献者的纵向活动记录。届时据此正式测算 GlobalCollabShare、AcademicShare，并评估诊断指标是否进入 OSDI。

## 验证范围

构建通过 51 个页面及本地链接检查。联动验证覆盖九个视图、72 组流向筛选组合、双图路径与数值一致、共享悬停/锁定/键盘、不同分母、模拟份额合计、来源链接及画布在演示容器中移动后的交互。对比发布前 HTML，2.1—2.5 和 2.7 完整保留。

检查导出的实际 SVG，调整标签避让与时间轴。当前环境没有可用的受支持浏览器控制能力，因此未进行真实浏览器像素布局验收；普通阅读与全屏最终效果供本轮线上审阅。
