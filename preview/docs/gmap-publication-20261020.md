# 2.7 G-Map 出版优化记录

## 本轮范围

按 2.1、2.2 基线保留五组图，统一图前问题、图后解读、行动建议及小节编号。网页与七页竖版 PDF 使用 `gmap_publication.py` 中的同一完整正文。治理图以基金会已有序列为默认入口，规模与影响份额并排呈现；地图与十个地区按钮在图内联动。正文和全屏复用同一图件，窄屏自动重排。

## 数据保护

`data.js`、`simulation.json` 与三份 CSV 字节不变；发布门禁锁定其 SHA-256。基金会、许可、木兰序列保持原值；地区、治理实践、维护、公共应用与 AI 检查数据为模拟，醒目标注，不构成实测结论。基金会清单与份额分母、许可多重标记规则等限制集中说明。

## 图文对齐

PDF 保留地图、折线、散点、堆叠条及矩阵的对应编码，治理实践使用一页续图。图片置于对应正文附近，图题下置居中；正文 11.2 pt，图中文字 8.5–10 pt。网页额外提供选择与比较，PDF 展开核心视角，读者无需操作即可理解。

## 验证

- 502 项双语 DOM 断言覆盖全部视图、选择操作、地图轮廓、来源对话框、全屏返回与窄屏重排。
- 240 项 CSS 级联断言覆盖明暗主题、正文、全屏和窄屏布局。
- 七页 PDF 已逐页渲染目检；文字、边界、矢量图及正文一致性通过自动检查。
- 未进行真实浏览器像素验证或实体打印；上述 DOM/CSS 检查不等同于浏览器截图检查。
