# 5.1-01 对齐 V-Map 的视觉层级

依据本轮两张参考图，将全球地图作为视觉主体。沿用 1280×560 逻辑画布与窗口高度适配；其余两幅图保持上一版布局。

- 世界底图等比尺度从 0.50 增至 0.90，主区域为 902×390；榜单收为右侧六行列表，分页放在列表下方。
- 顶部只保留资产切换、指标选择和搜索。国家到组织的下钻与返回操作放在地图及所选对象卡，搜索在返回国家列表时清空。
- 平台总量、地域样本和组织数合并为地图顶部说明；底部以两个 390×108 的趋势卡和一个所选对象卡呈现。
- 6／12／18 个月与年度积累保留为四个紧凑切换项。所有趋势点可读取，完整记录继续导出。
- 数据表、SVG、CSV 收入“数据与导出”菜单，支持 Esc 关闭与键盘焦点返回。

验证：两种主题的 SVG 图面；指标选择、搜索、分页、组织下钻、月度与年度切换、菜单、数据表、全屏以及 CSV/SVG 导出；全章数据边界与页面构建检查通过。浏览器控制技能不可用，未进行真实浏览器排版验证。
