## 分工与状态

主编负责范围、关键论断、口径取舍、署名与最终定稿；内容/数据协作者提供正文、可核验数据、来源和复核；实现方负责网站模板、图表交互、构建、校验与发布操作。具体协作者姓名由主编指定，本规划不自动分派成员或发送通知。

每个内容单元依次经过：**待补 → 初稿 → 数据已核验 → 编辑已通过 → 网页/打印已验收 → 已冻结**。勾选任务表示达到该任务的验收标准，不能把“文件存在”当成“可发布”。

协作以完整小节或页面为单元推进。实现方先完成可审阅的结构与整理，再集中提出影响方向、结论或发布范围的关键问题；细节留在对应任务中处理，已确定事项直接执行。

建议每轮交流直接使用任务号，例如：“开始 B03，这是 2.1 的数据与来源”或“C02 已更新，请复核并接入预览”。
