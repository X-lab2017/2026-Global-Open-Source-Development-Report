# 全书架构与制作模式

2026-10-11 · v0.2 架构工作版。主编最新要求：**先把整个报告的架构和模式建立起来，停止逐条细问统计细节。**

## 当前采用的全书架构

执行摘要 → 独立引言 → 六章 → 附录 A/B/C → 数据与引用。六章共 30 个小节；第六章的 6.5 承担结语。

| 章节 | 角色 | 主要形式 |
|---|---|---|
| 第一章：开源发展目标与指标体系 | 目标：解释如何衡量 | 圆盘、指标字典、覆盖说明 |
| 第二章：全球开源生态观测地图 | 观测：说明规模与结构 | 地图、年度趋势、对照表 |
| 第三章：全球开源影响力排行榜 | 评估：比较生态位置 | 分类榜单、年度对照、样本说明 |
| 第四章：全球开源技术全景洞察 | 洞察：解释技术生态 | 分层全景、代表项目、案例 |
| 第五章：全球开源大模型发展洞察 | 治理：解释供给、复用与开放 | 趋势、关系图、开放属性矩阵 |
| 第六章：未来展望与行动建议 | 行动：回应研究发现 | 发现—主体—行动—跟踪指标 |

3.6 负责模型影响力榜，4.2 负责模型技术生态，5.1—5.3 负责供给、网络机制和开放治理。使用同一数据与方法版本，交叉引用。

附录 A 集中方法与来源；附录 B 使用主编指定飞书文档；附录 C 为开源 AI DPG 研究评估框架。引言优先面向政府与国际组织决策者，已独立起草。

## 一套内容，多种呈现

每节采用：**研究问题 → 核心发现 → 图表证据 → 解读与案例 → 行动建议 → 方法与来源**。

四类内容的模板有所侧重：

| 类型 | 固定模块 |
|---|---|
| 生态观测 | 问题、关键变化、地图/趋势、区域对照、解释与边界 |
| 影响力榜单 | 对象与样本、排行、年度变化、解读、方法入口 |
| 技术全景 | 分类层次、代表项目、演进证据、案例与启示 |
| 治理与行动 | 问题、证据、属性/行动矩阵、适用条件与后续观察 |

统一的图表块包括标题、一句话读图、图形、数据表、CSV、来源和方法。资料尚未齐备时保留位置与说明，不绘制虚构统计值。交互版本服务探索，静态版本服务 PDF 与引用。

## 网站的阅读模式

- 首页保留已经确认的圆盘、留白、配色、深浅模式和双语切换。
- 全书目录集中展现六章及前后置内容，读者从整体选择路径。
- 每章有独立地址、章内目录、稳定小节锚点、前后章导航与源稿入口。
- 方法、宣言、DPG 框架和下载各有独立页面。
- 当前是架构预览：展示研究问题、拟用图表和稿件入口；完整正文及核验后的结果逐章接入。
- 英文导航与架构同中文对应；全文英文翻译和正式 PDF 在内容稳定后完成。

## 协作方式调整

**我先整理成完整可审阅的版本，你按整章或整阶段判断。**

1. **框架与模式**：先看全书目录、章节角色、阅读方式和统一模板。
2. **样章与填充**：选定样章，展示正文、图表和静态输出的完整效果，再按章扩展。
3. **集中复核**：每章完成时集中处理会改变结论的方法、数据和来源问题。
4. **定稿与发布**：全书编辑、双语与 PDF、版本冻结、正式发布。

常规排版、导航、文件组织和已确认规则由实现方直接完成。只有影响全书方向、关键结论、重要取舍或正式发布的事项才集中提问。已有 43 项清单继续作为后台执行清单，不再逐项转化成主编问答。
