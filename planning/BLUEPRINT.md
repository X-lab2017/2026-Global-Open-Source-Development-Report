# 报告整体设计方案

本方案基于 2026-10-11 的仓库快照及主编已确认的品牌与交互预览。标为“建议”的内容需要按工作清单冻结，不能直接视作正式研究结论。

## 1. 产品定位与交付物

将报告建设为一个每年可延续的研究出版物：**同一套经过审阅的内容和数据，同时支持在线阅读、交互探索与静态引用。**

主要读者与阅读路径：

| 读者 | 首要问题 | 入口与目标阅读时长（设计目标） |
|---|---|---|
| 政府、国际组织与峰会听众 | 今年发生了什么，为什么重要，下一步做什么？ | 首页 → 执行摘要 → 行动建议，约 3—5 分钟 |
| 企业、基金会和社区负责人 | 我所处的区域、组织或技术领域有什么变化？ | 观测地图 → 榜单/专题 → 方法说明，约 15—30 分钟 |
| 研究者与数据使用者 | 结论如何产生，数据是否可比较、可复用？ | 具体图表 → 数据表/CSV → 指标定义/来源/版本 |

正式交付以中文在线报告为先，配套中文 PDF、公开可分享的数据包与方法附录；英文在线版与英文 PDF 在中文冻结后制作，并用于 AI for Good 发布。摘要图、封面、分享图和二维码组成发布素材包。视频与演讲稿作为可选后续项目，不进入本轮必做清单。

## 2. 内容架构：摘要 + 六章 + 三个附录

建议保留仓库现有第六章，把“结语”收在 6.5，避免同时维护一个独立结语。统一 `outline/目录.md`、`outline/正式大纲.md`、README 与网站导航。

| 单元 | 唯一要回答的问题 | 应交内容 | 在线呈现与范围控制 |
|---|---|---|---|
| 执行摘要 | 今年最值得关注的变化是什么？ | 5—7 条有证据的发现、3—5 项行动建议；建议 800—1200 中文字 | 首页摘要；每条发现链接到图表或章节 |
| 引言 | 为什么今年需要这份报告？ | 主编已决定重新撰写；建议约 600—800 字年度背景、范围与阅读说明，优先面向政府与国际组织决策者 | 独立研究导读；宣言全文放附录 |
| 第一章：OSDGs 与 OSDI | 如何衡量开源发展？ | 1.1 价值与背景；1.2 四支柱十维度；1.3 指标、角色、口径与覆盖 | 圆盘 → 支柱 → 维度 → 指标 → 相关章节；保留现有交互语言 |
| 第二章：全球生态观测 | 全球生态的规模与结构怎样变化？ | 2.1 活跃、2.2 贡献、2.3 项目影响力、2.4 人才、2.5 多样性、2.6 治理公益、2.7 资产 | 地理图、趋势图、对照表；七类观测是主题视角，不是新增七个一级支柱 |
| 第三章：影响力榜单 | 谁在贡献，位置如何变化？ | 3.1 行政区划、3.2 企业、3.3 基金会、3.4 项目、3.5 新势力、3.6 模型 | 可排序表、年度对照、来源说明；同一榜单只比较同口径对象 |
| 第四章：技术全景 | 关键技术生态怎样组织和演进？ | 4.1 Agentic AI、4.2 AI 大模型、4.3 云、4.4 数据库、4.5 RISC-V、4.6 PyTorch | 分类全景、代表项目、趋势证据、案例；先做清晰图表再考虑复杂网络交互 |
| 第五章：大模型发展与治理 | 模型的供给、复用与开放实践怎样改变开源？ | 5.1 供给与贡献；5.2 网络与影响力；5.3 开放分级与治理 | 供给趋势、复用关系、开放属性矩阵；区分实证结果与研究建议 |
| 第六章：展望与行动 | 各类参与者下一步做什么？ | 6.1 趋势；6.2 政府；6.3 企业；6.4 社区与国际合作；6.5 结语 | 按读者角色查看“发现—行动—跟踪指标”；预测与已观测事实分开标记 |
| 附录 A | 指标与计算能否解释清楚？ | 指标字典、数据来源、算法版本、覆盖、缺失处理、局限 | 可检索方法库；图表可直接跳到对应定义 |
| 附录 B | 报告采用哪一份宣言？ | 采用主编已指定的[飞书文档](https://f16qo26uhe1.feishu.cn/wiki/BBjrwWhukifCqukvEwSct9EYnMf)，记录正式题名、版本与原文链接 | 来源已定；最新正文核对后收录，仓库旧快照不自动视为最新定稿 |
| 附录 C | AI 数字公共品如何评估？ | 现有 DPG 框架、适用边界、评分/分级方法与案例证据 | 作为研究评估框架呈现；区分拟议分级和已实际实施的认证 |

### 大模型内容的三章分工

| 位置 | 负责 | 交叉引用 |
|---|---|---|
| 3.6 | 按明确版本的 ModelRank 方法给出榜单、变化、样本与限制 | 方法和网络解释链接 5.2 |
| 4.2 | 模型技术生态的分层、领域、项目与基础设施关系 | 全球供给统计链接 5.1，开放治理链接 5.3 |
| 5.1—5.3 | 解释供给变化、复用机制、开放属性与治理意义 | 复用 3.6 的同一结果数据，不重新计算一套榜单 |

若 3.6 的方法或数据未达到验收条件，应明确标为“研究中”，暂不发布名次；用样本观察与方法说明代替，不能临时拿下载量代替 ModelRank。其他缺数据指标同样执行透明的覆盖说明。

## 3. 网站信息架构

首页继续沿用已确认的留白、圆盘、海军蓝和轻交互。完整报告采用可直达、可分享的独立章节地址，长正文不全部塞进首页标签页。

建议正式路径（待主编选择官网域名后配置）：

| 路径 | 内容 |
|---|---|
| `/2026/zh/` | 中文封面、摘要入口、圆盘入口、章节目录、下载 |
| `/2026/zh/summary/` | 执行摘要 |
| `/2026/zh/framework/` | 四支柱、十维度、指标覆盖与定义 |
| `/2026/zh/chapters/01/` 至 `/06/` | 六章正文，节与图表有稳定锚点 |
| `/2026/zh/methodology/` | 附录 A、口径、数据来源与限制 |
| `/2026/zh/appendices/declaration/`、`/dpg/` | 附录 B/C |
| `/2026/zh/downloads/` | PDF、可发布 CSV、引用方式、许可与版本记录 |
| `/2026/en/…` | 同一内容 ID 的英文版本；尚未完成时显示翻译进度，不放空白翻译 |

图表直达示例：`/2026/zh/chapters/02/#fig-2-1-3`。内容 ID 固定；显示编号和中英文标题可以变。已有 `fig-章-节-序号` 的文件名继续保留，不为改版批量改名。

## 4. 六类页面/组件足够支撑首版

| 模板 | 必需功能 | 验收重点 |
|---|---|---|
| 首页/摘要 | 关键发现、章节入口、圆盘、PDF 入口 | 读者能在短时间理解年度主张 |
| 章节正文 | 章内目录、阅读位置、上一/下一节、来源脚注 | 目录与地址稳定；移动端连贯阅读 |
| 图表块 | 简明标题、一句话读图、单位/周期、交互、数据表、CSV、来源 | 图与正文数值一致；关掉交互仍能读懂 |
| 榜单块 | 排序、筛选、同口径年度对照、方法说明 | 新入榜/缺失/并列规则清楚；无数据不自动补零 |
| 指标定义 | ID、定义、算法、角色、SDG 对应、覆盖与关联章节 | 29 个条目状态清楚；SDG 对应不被误读为影响量化结果 |
| 下载/引用 | 正式版本、发布日期、PDF/数据、引用格式、更正记录 | 匿名访问和下载可用，版本一致 |

首版优先交互：深浅模式、中英文、章节锚点、圆盘筛选、趋势切换、榜单排序、数据表与下载。暂停复杂 3D、大规模实时网络、登录收藏、自定义仪表盘和全天候实时抓取；年度报告先使用冻结快照，避免发布后数字自行变化。

## 5. 视觉规范：保持已确认体系

- OSDG 为对外品牌字标；正文概念采用“开源发展目标（OSDGs）”；指标体系采用用户指定的“开源发展目标指标体系（The OSDGs Indicator System，OSDI）”。英文全称不按旧缩写机械推导。全站与 PDF 使用同一术语表。
- 四支柱名称与顺序固定：X1 人才规模与多样性；X2 技术产出与开放供给；X3 全球连接与网络效应；X4 开源善治与公共价值。十维度按 2/3/3/2 分组，沿用品牌库标准名称。
- 浅色背景 `#F3F8FA`，深色背景 `#0A2C49`；不把深色简化为纯黑。使用品牌库对应深浅标识，纯黑/纯白版用于单色印刷和特定材质。
- 四支柱沿用青、蓝、紫、绿语义色；章节编号采用中性主色。区域或模型的系列颜色保持跨图稳定，不把区域系列误称为支柱色。
- 圆盘表达结构，不表达权重、排名或完成比例。29 个指标的“北极星/诊断/驱动”也不自动形成权重。
- 标题、图注和数据表提供中文优先排版。英文使用同一组件并适应更长文本；图表不能只靠颜色区分，需要标签、线型或可读表格。
- 普通正文、图表与海报共用品牌资产和字级规则；方法说明保留编辑质感和足够留白。动效服务切换与定位，提供减少动效模式。
- 对齐 AI for Good 的国际发布场景，在封面/联名区使用经确认的大会及机构素材。联合国/大会标识按已确认用途与素材版本管理，主品牌保持独立可用。

## 6. 内容与数据的单一发布来源

建议保留现有分工：飞书继续协作写作；GitHub 作为每次网站和 PDF 构建的**发布依据**。每节设置负责人和同步时间，以 GitHub 审阅通过的快照生成网站，减少两边同时改动造成的覆盖。

每次交付最小单元：一份 Markdown 正文 + 相应 CSV + 图表说明/来源 + 必要原始证据。飞书表格导出成可审查 CSV/Markdown；外链图片转为仓库内可访问素材或用数据重绘。不会自动把两边无审查双向覆盖。

| 仓库 | 责任 |
|---|---|
| 本报告仓库 | 正文、口径、图表数据、打印图、方法和版本；建议新增网站实现目录与发布配置 |
| `osdg-brand` | 字标、图标、圆盘、色值和使用规范；按固定版本消费 |
| 当前预览站 | 已确认体验的实现参照与持续预览；正式迁移/同步时保留单一代码维护入口 |

后续建议在报告仓库新增 `web/`（网站模板）、`content/manifest.json`（目录和内容状态）、`data/meta/figures.csv`（图表索引）与发布工作流；此次仅规划，不先创建另一套正文。已有 `chapters/`、`appendices/`、`data/`、`figures/`、`scripts/` 保持职责。

指标权威定义最终归于报告 `data/meta/`，品牌库保存稳定 ID、标签、顺序与视觉映射。当前 29 条先作为就绪表基线，不把品牌清单当作完整计算公式。品牌、指标字典、网页之间通过 ID 对齐。

图表元数据至少包含：图 ID、章节、标题、指标 ID、CSV、静态图、单位、统计期、快照时间、来源 URL/版本、转换脚本、缺失处理、审阅人和状态。沿用“一图一同名 CSV”；关系图可补边列表；概念图登记“非统计图”，不伪造 CSV。

## 7. 数据与研究验收

1. **时间**：仓库现定 2025-07-01—2026-06-30 为 2026 报告期，需主编确认。存量时点、年度流量、截至某月快照分别标记；2022—2026 历史序列要明确各年窗口。
2. **对象**：平台账号不自动等于跨平台去重自然人；仓库不自动等于项目。地区、公司、基金会、模型家族的归属与聚合规则留档。
3. **可比性**：全球与中国多平台口径、已知/未知地区、有效行为、机器人和镜像、缺失值、并列名次、榜单进入条件都需定义。
4. **算法**：OpenRank 贡献度、OpenRank 影响力、ModelRank、下载量、活动计数分别呈现；不给不同算法得分拼出无方法依据的总排名。
5. **来源**：ATOM 与 LFX 可作为补充证据。ATOM 各图时间不同；当前 LFX 快照是 Linux Kernel、全周期活动计数，不可代替全球年度 OpenRank。
6. **复核**：主要百分比、同比、份额、Top N 和摘要结论从已审查数据重算；样本先闭环，再逐节扩展。
7. **覆盖**：29 项指标逐项填写“本期可发布/试验性/本期未观测”。缺失不等于零；首页明确本期覆盖，避免暗示已测全体系。
8. **边界**：“开放权重”“开放代码/数据”和报告采用的“开源”判定分别说明；不以开放排名或热度推断性能、社会效果或正式认证。

## 8. 多形态输出与发布顺序

同一份内容源生成在线版和 PDF。交互图同时保留确定性静态图；PDF 固定版本、章节编号、来源、页码和引用格式，支持黑白可读。在线图表采用当前主题色，不改数值或算法。中文修改应标记关联英文为“待同步”。

建议里程碑，按依赖推进，不把相对周数当成已确认发布日期：

| 里程碑 | 可验收成果 | 建议工作段 |
|---|---|---|
| M1 结构冻结 | 目录、术语、报告期、29 条就绪表 | 第 1 个工作段 |
| M2 完整样章 | 第一章 + 2.1 的正文/CSV/交互图/静态图/来源闭环 | 第 2 个工作段 |
| M3 中文内容齐套 | 第二至六章、附录及所有采用图表达到研究审阅标准 | 后续逐节迭代；写作与网站可并行 |
| M4 中文候选版 | 全站、PDF、下载包、链接和移动端验收；主编签字 | 发布前冻结段 |
| M5 英文与峰会版 | 审校后英文、分享图、引用、二维码、会场屏幕适配 | 中文冻结后；以实际峰会日倒排 |
| M6 正式公开 | 正式域名、公开访问、GitHub Release、归档与更正入口 | 主编批准的发布日 T |

若团队需要日历，可在任务负责人和资料到位程度确认后，以“口径/样章约 1—2 个工作周，后续内容与实现约 3—5 个工作周”为初步排期讨论范围；数据补采和外部审校可能主导进度，不能据此保证交付日。

峰会节点用 T 表示：T−14 天中文与核心数据冻结；T−7 天英文和引用核对；T−3 天会场屏幕、链接、二维码和离线 PDF 演练；T 日发布；T+7 天汇总勘误。具体日期、峰会届次和发布场次待确认。

## 9. 正式上线的完成标准

所有对外页面均达到既定发布状态，无无法访问的飞书嵌入、虚设下载按钮或未说明的示例结果；全文与图表来自同一冻结版本。关键数据、品牌/署名/第三方素材范围、英文术语均有人复核；浏览器、手机、键盘、深浅模式、打印与匿名访问实际验证完成。主编对公开范围和版本给出发布批准后再开启公开访问。

发布包记录：版本号、发布日期、内容 commit、指标方法版本、品牌版本、数据快照与更正说明。年度数据不静默更新；修订发布补丁版，下一年度保留 `/2026/` 的稳定引用入口。
