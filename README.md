# 2026 全球开源发展报告（Global Open Source Development Report 2026）

> 年度主线：**从普惠到质量，从参与到影响**
>
> 逻辑主线：目标 — 观测 — 评估 — 洞察 — 治理 — 行动

《2026 全球开源发展报告》追踪全球开源生态在人工智能时代的演进，以开源发展目标（OSDGs）及开源发展目标指标体系（The OSDGs Indicator System，OSDI）组织研究。本仓库用于报告协作与发布；当前正文为初稿，数据与结论仍需逐节核验。

从[报告建设工作台](planning/README.md)进入，查看[六章目录](outline/目录.md)、[内容架构](content/README.md)与[逐项任务](planning/WORKLIST.md)。先选一节，提供核心发现、材料和来源即可开始整理。

## 目录结构

```
├── outline/                 # 大纲、目录、执行摘要
├── content/                 # 内容索引、页面模式与填写约定
├── chapters/
│   ├── 引言-宣言.md          # 旧宣言快照参考；新版引言独立重写
│   ├── chapter1/            # 开源发展目标（OSDGs）与开源发展目标指标体系（OSDI）
│   ├── chapter2/            # 全球开源生态观测地图（GOSO，2.1–2.7）
│   ├── chapter3/            # 全球开源影响力排行榜（GOSR）
│   ├── chapter4/            # 全球开源技术全景洞察（GOSL）
│   └── chapter6/            # 未来展望与政策建议
├── appendices/              # A：指标与方法；C：DPG框架；B宣言待核对后收录
├── data/                    # 数据资产（规范见 data/README.md）
│   ├── meta/                # 指标定义与口径（附录 A 各表的 CSV 版）
│   ├── processed/           # 图表源数据：每张图对应一个同名 CSV
│   └── raw/                 # OpenDigger 原始导出（只增不改）
├── figures/                 # 报告图片（与 data/processed/ 同名同构）
└── scripts/                 # 数据计算与图表生成脚本
```

## 数据规范（协作者必读）

报告遵循「**一张图 ↔ 一个同名 CSV**」原则：正文每张图的数据存放于 `data/processed/<章节>/fig-<章号>-<节号>-<序号>_<描述>.csv`，图片存放于 `figures/` 同章同主干名。新增图表时必须同时在 `data/README.md` 的索引表登记。详见 [data/README.md](data/README.md)。
