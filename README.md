**Global Open Source Development Report 2026**

## 全书结构

| 部分 | 内容 |
|---|---|
| 执行摘要与引言 | 年度发现、研究背景与阅读导引 |
| 第一章 | 开源发展目标与指标体系 |
| 第二章 | 全球开源生态观测地图 |
| 第三章 | 全球开源影响力排行榜 |
| 第四章 | 全球开源技术全景洞察 |
| 第五章 | 全球开源大模型发展洞察 |
| 第六章 | 未来展望与行动建议，含 6.5 结语 |
| 附录 A/B/C | 方法与数据／指定宣言／开源 AI DPG 评估框架 |

品牌标识为 OSDG，目标框架为开源发展目标（OSDGs），指标体系为开源发展目标指标体系（The OSDGs Indicator System，OSDI）。沿用四支柱、十维度和 29 项指标清单；实际观测覆盖随各章核定。

主统计期为 2025-07-01—2026-06-30，2022—2026 各年采用上年 7 月至当年 6 月。代码生态以 GitHub 为主范围，Gitee、AtomGit、GitLab 作补充。详见 [数据说明](data/README.md)和[已作决策](planning/DECISIONS.md)。

## 内容与实现

| 路径 | 职责 |
|---|---|
| `content/manifest.json` | 统一章节 ID、目录、呈现类型、源文件与状态 |
| `chapters/`、`outline/`、`appendices/` | 正文、摘要、目录与附录；缺稿已有结构入口 |
| `data/`、`figures/` | 图表数据、方法元数据与静态图 |
| `web/` | 由统一目录生成阅读框架的模板和脚本 |
| `planning/` | 协作模式、工作清单、决策、待核验问题 |

飞书继续协作写作，GitHub 保存可审阅快照。统计图遵循“一张图 ↔ 一个同名 CSV”；数据未核验的小节维持初稿或结构稿状态。现有原稿保留，完整正文按章整理进入阅读模板，不因文件存在而自动视为可发布。

生成与同步说明见 [web/README.md](web/README.md)。框架、内容、研究核验、双语审校和正式发布是独立阶段。
