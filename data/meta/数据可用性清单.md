# OSDI 数据可用性清单

盘点日期：2026-10-12。基线：主分支合并版本 `b9a6210d58bee59b6e39ce13b74efd2b3ffb8b7c`（包含第三章新增数据）。此清单描述当前仓库文件与证据状态，不代表团队没有其他数据。

## 当前结论

- `data/processed/` 共有 **34 份 CSV**：第二章 13 份、第三章 21 份；第四、第五章尚无 CSV 数据。
- 二十九项指标均已登记工作定义和准备状态；已有文件与指标是否同口径，需要逐项对应，不能仅凭名称视为指标已经算完。
- 本轮核验文件存在、字段、行数和关联关系；没有重算或改动现有数据值，没有把关联资料标记为已完成端到端复现。
- LFX korg 与 ATOM 两组外部快照只用于开篇故事和背景引用，**不进入 OSDI 的计算、评分、正式排名或可用指标计数**。
- 数据由报告负责人统筹补充；新增文件后同步更新本清单及机器可读[文件清单](dataset_inventory.csv)。

## 二十九项指标状态

| 指标代码 | 指标 | 当前数据状态 | 形成正式结果还需的证据 |
|---|---|---|---|
| DevScale | 活跃开发者规模 | 关联资料已入库 | 补齐平台覆盖、身份映射与机器人过滤记录 |
| TalentDensity | 人才聚集密度 | 尚无匹配数据 | 人口来源与时点待登记；不能用 OpenRank 人均贡献代替 |
| NewcomerGrowth | 新晋开发者增速 | 尚无匹配数据 | 需要首见时间和历史覆盖；基期为零时不计算增速；不是注册数或留存率 |
| GlobalCollabShare | 全球开源协作占比 | 关联资料已入库 | 固定贡献度量及地区层级；未知地域覆盖另列；不能以 Top10 子样本推全局 |
| AcademicShare | 学术机构贡献占比 | 尚无匹配数据 | 机构分类和历史关联待补；不依据姓名或邮箱片段直接推断 |
| ActiveRepo | 有效活跃仓库规模 | 关联资料已入库 | 历史 OpenRank 可继承，不能仅以大于零判为当期活跃；平台镜像另行核验 |
| OpenRankContrib | 代码协作贡献度 | 关联资料已入库 | 现有贡献度文件需补算法类型、版本、月度或年度聚合和覆盖 |
| ReviewedPR | 高质量 PR 合入量 | 尚无匹配数据 | 评审条件和机器人规则待定；经过评审仅是质量代理，不证明代码质量 |
| OpenModelRelease | 开源模型发布量 | 尚无匹配数据 | 需模型身份、发布时间与开放资格表；公开可见不自动计入；未知地域仍入总量 |
| ModelSupplierDiv | 模型供给方多样性 | 尚无匹配数据 | 需发布方实体归并与版本去重；不使用故事快照填补 |
| OpenDatasetRelease | 开源数据集发布量 | 尚无匹配数据 | 需数据集许可、可获取条件及发布时间；未知发布方或地域单列 |
| DataSupplierDiv | 数据供给方多样性 | 尚无匹配数据 | 发布方实体归并、开放资格与分母待补 |
| OpenRankInflu | 代码仓库影响力 | 关联资料已入库 | 补齐网络范围、算法版本、历史继承、项目年度边界与聚合规则 |
| HighImpactRegion | 高影响力区域数量 | 关联资料已入库 | 排名范围、绝对阈值或分位数须明确；不默认前5% |
| HighImpactOrg | 高影响力组织数量 | 关联资料已入库 | 组织边界、重叠处理和阈值待补 |
| HighImpactProj | 高影响力项目数量 | 关联资料已入库 | 样本覆盖与阈值待补；未映射仓库不自动当作独立项目 |
| HighImpactTalent | 高影响力人才数量 | 关联资料已入库 | 不能把跨年累计误作当年值；Top10 城市表不覆盖全部人才 |
| ModelAdoption | 模型采用度 | 尚无匹配数据 | 不把下载当作用户数；本期无 OSDI 可用的匹配数据 |
| ModelCommunityHeat | 模型社区热度 | 尚无匹配数据 | 区分自动化、关注度和贡献；各信号窗口待固定 |
| ModelRank | 模型生态衍生力 | 尚无匹配数据 | 需边关系规则、模型去重、算法版本及结果；外部衍生数量不是 ModelRank |
| DataAdoption | 数据采用度 | 尚无匹配数据 | 下载不等于已用于训练；来源覆盖待补 |
| DataCommunityHeat | 数据社区热度 | 尚无匹配数据 | 区分关注、维护和实质复用；信号窗口待固定 |
| DataEcoReuseRate | 数据生态复用率 | 尚无匹配数据 | 需复用边与观测覆盖；无记录不直接等于未复用 |
| NeutralityRatio | 基金会托管比例 | 关联资料已入库 | 现有文件是基金会项目 OpenRank 份额与活跃仓库数，均不能直接代替托管项目比例 |
| GovBalance | 治理主体均衡度 | 尚无匹配数据 | 不得用代码贡献组织分布直接代替治理权力分布 |
| ComplianceLicenseCov | 合规许可覆盖率 | 关联资料已入库 | 是元数据层的许可覆盖观测，不是法律合规审计；需未知许可和完整分母 |
| DPGCoCreation | 数字公共品共建度 | 尚无匹配数据 | 明确正式认可或研究候选身份；不得自行宣称 DPGA 认证 |
| LicenseOpenness | 高开放度许可占比 | 关联资料已入库 | 需分类表与完整分母；不能把宽松许可简单等同于更高公共价值 |
| AIAssetTransparency | AI 资产透明度 | 尚无匹配数据 | 检查项、适用对象与证据链接待固定；不以文档存在证明真实性 |

方法草案与已确认规则分别见[指标字典](osdi_indicator_dictionary.csv)的 `method_status` 字段；关联资料入库并不构成该方法已执行的证明。

## 下一批数据的最小交付信息

每份数据至少附：统计对象与范围、起止时间或快照时点、平台与来源、单位、计算/查询或导出版本、去重与筛选说明、缺失与未知处理。算法、身份/项目/地域映射版本按实际使用记录。允许先上传已有结果并标注待补，不因缺少完整管线而阻止入库；正式排名与结论采用经过相应核验的数据。
