# raw/：原始数据归档

本目录存放从 OpenDigger 导出的**原始数据**，是整条管线的起点。

## 规则

1. **只增不改**：原始数据一旦归档不得修改；发现错误时新增修正版本，旧文件保留
2. **按统计周期分目录**：`raw/2026/` 对应统计周期 2025-07-01 ~ 2026-06-30
3. 每个导出批次在批次目录放一个 `EXPORT_INFO.md`，记录：导出时间、OpenDigger 版本/接口、查询参数、操作人
4. 单文件 > 50 MB 用 Git LFS；> 100 MB 不进 git，放外部存储并在此处登记链接
