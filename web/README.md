# OSDG 全书阅读框架

沿用现有静态预览站，无新运行依赖。`content/manifest.json` 为目录、章节 ID、源文件、状态与呈现类型的维护入口；`chapters/` 等目录继续保存正文。引言从其 Markdown 读取，不维护另一套正文副本。

```bash
python3 web/build_reader.py --output /path/to/site/dist
```

输出 `/2026/zh/` 与 `/2026/en/` 目录、六章、摘要、引言、三个附录及下载页面，共 26 页；包含章内锚点、源稿链接、双语导航、深浅主题与打印样式。当前框架显示章节问题与呈现计划，完整正文仍通过源稿入口读取。现有首页圆盘、指标探索与趋势试读保留。

## 维护与同步

本仓库维护 `content/` 和 `web/`。在私密 Sites 源仓库中同步这些文件和引言源文件，再运行生成器。该同步是单向的发布快照，不在两边独立改写目录或研究正文。Sites 保留原首页实现与托管身份，GitHub 草案分支保存本次可审阅改动。

首页增加完整目录入口；章节试读增加独立章节链接。正式托管迁移、完整正文转换和 PDF 管线按后续工作完成，本轮不改变公开范围。

## 状态约束

- `draft`：已有初稿，未因此视为已通过数据审阅。
- `outline`：已建立写作结构，研究结果待补。
- `source-confirmed`：指定来源已确定，最新正文仍需核对。
- 结构英文版已提供，不代表英文全文已审校。

生成器检查六章、30 个稳定小节 ID 与交叉引用；部署前另检查 JavaScript 语法与所有生成页面的内部链接。浏览器实测状态见 `planning/FRAMEWORK_MODE.md`。
